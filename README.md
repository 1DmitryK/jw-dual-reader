# JW Dual Parallel Reader

Приватный автономный параллельный браузер для изучения и параллельного сравнения материалов сайта `jw.org` на нескольких языках (Украинский, Русский, Английский) в двух независимых окнах.

- 100% клиентское веб-приложение (PWA)
- Полная приватность: отсутствие трекеров, аналитики и сторонних серверов
- Поддержка iPad Split View, macOS и Windows
- Доступно онлайн: [https://1dmitryk.github.io/jw-dual-reader/](https://1dmitryk.github.io/jw-dual-reader/)
